Privacy Policy

GCal Extractor Pro™ respects your privacy.

  • 1. Data Accessed: The application requests read-only access to Google Calendar™ events and Google Tasks™ lists solely to extract user-requested data. It requests Google Drive™ and Google Sheets™ access solely to create and write the extracted data into the user designated Google Sheet™ (and Microsoft Excel™ sheet for paid users).
  • 2. Data Usage: Data is processed locally within the user session and script execution environment to perform requested calendar and task exports.
  • 3. Data Sharing: We do not sell, share, rent, or monetize personal data or Google™ user data with any third parties.
  • 4. Data Storage & Protection: All data extraction occurs directly between your Google™ account and your Google Sheets™. No calendar, task, or personal data is transmitted to, stored on, or processed by external third-party servers.
  • 5. Data Retention & Deletion: Because no user data is stored on external servers, no data is retained by the developer. Users can revoke application access at any time via their Google™ Account security settings.
