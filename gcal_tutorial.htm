GCal EXTRACTOR PRO™

Quick Cheat Sheet & User Guide

[added to site 2026]

Step-by-step operational instructions and cheat sheet for configuring and running GCal Extractor Pro™.

1. Initial Setup & Authorization (one time only)

  • Google™ Account Sign-In: Launch the application and sign in using your standard Google™ account credentials.
  • OAuth Consent Grant: Review the requested read-only scopes for Google Calendar™ and Google Tasks™, alongside Google Sheets™ and Google Drive™ write permissions. Click grant to permit secure session token generation.
  • Local Token Storage: Authorization tokens are stored securely in your local environment session profile.

2. Configuring Extraction Parameters

  • Date Range selection: Select a date range from the dropdown or specify your exact start and end date parameters within the extraction control panel.
  • Calendar target: Select the specific target calendar from the dropdown. If you want to use multiple calendars, leave this blank and delete any calendars from the CalendarBatch tab that you want to exclude. (Tasks are automatically included in the paid versions)
  • Pro tip: If you accidentally delete a calendar you wanted to include, you can Select Diary Extractor from the menu bar and Refresh Calendars & Dropdowns to reload the complete list!
  • Output filename: Enter the name you want your output file to have, it will be automatically preceeded with a date-time stamp for easy sorting and storage. The calendar name will also be appended to your filename for easy identification.
  • Output directory: By default the app drops all output files into GSheets Dump root directory of your Google Drive™. If you would like to use a different target directory please refer to the Helpers tab within the app for instructions.

3. Executing the Extraction

  • Run Extraction: In the menubar of the app, click Diary Extractor followed by Run Diary Extract and that is it!
  • Data Output: Extracted event entries and task details populate directly into your designated Google Sheet™ in structured tabular format. If using a paid version the data can also be exported directly into Microsoft Excel™ worksheets.
  • Session Close: Close the application interface upon completion. No data is retained on or transmitted to external servers. Any selections you have made in the main app page will be retained, and your predefined title query lists are saved internally for your next use if needed.

Troubleshooting & Support

If you encounter authorization prompts or connectivity blocks:

  • Ensure your Google™ account permissions allow access for this application.
  • Verify active internet connection to ensure you access your latest data from Google™.
  • For tier upgrades or technical inquiries, visit the main GCal Extractor Pro™ Support Page.
